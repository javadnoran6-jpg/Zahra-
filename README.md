# زهرا VPN — نسخه اندروید (هسته Aether)

ساخته شده توسط **فاطمه زهرا ساعی**

```
اینستاگرام → VpnService (TUN) → hev-socks5-tunnel → SOCKS5 127.0.0.1:1819 → هسته Aether → اینترنت
```

هسته‌ی واقعی [Aether](https://github.com/CluvexStudio/Aether) (نسخه رسمی v2.3.0) داخل APK قرار می‌گیرد.
Aether پورت SOCKS5 را فقط وقتی باز می‌کند که تونل از اول تا آخر تست شده باشد؛ پس «نمایشی» نیست.

## ساخت APK با GitHub (بدون Android Studio)

1. در GitHub یک مخزن جدید بسازید.
2. **همه‌ی فایل‌های این پوشه** را در آن آپلود کنید. حتماً پوشه‌ی `.github` (مخفی) هم برود.
   ساده‌ترین راه: Git یا GitHub Desktop. در آپلود وب، پوشه‌ها را با drag & drop بکشید.
3. تب **Actions** → ورک‌فلو **Build APK** → خودش اجرا می‌شود (یا Run workflow).
4. بعد از ۱۰ تا ۲۰ دقیقه، پایین صفحه‌ی اجرا در **Artifacts** فایل `ZahraVPN-apk` را بگیرید.
   - `app-universal-release.apk` روی همه‌ی گوشی‌ها نصب می‌شود (حجم بیشتر).
   - `app-arm64-v8a-release.apk` برای اکثر گوشی‌های امروزی (سبک‌تر).
5. (اختیاری) برای نسخه‌ی قابل‌بروزرسانی، یک keystore بسازید و در Settings → Secrets این‌ها را بگذارید:
   `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`. بدون آن‌ها هر بار کلید موقت ساخته می‌شود.
6. اگر Aether نسخه‌ی جدید داد، فقط `AETHER_VERSION` را در بالای `build-apk.yml` عوض کنید.

## روش‌های اتصال

| روش | کی استفاده شود |
|---|---|
| هوشمند | پیش‌فرض: به ترتیب H3 ← H2 ← H2+Fragment ← Gool ← WireGuard را امتحان می‌کند |
| HTTP/3 | سریع‌ترین، اگر UDP/QUIC کند نشده باشد |
| HTTP/2 | وقتی اپراتور UDP را کند یا قطع می‌کند (معمولاً مفید روی سیم‌کارت) |
| H2 + Fragment | وقتی هندشیک TLS بسته می‌شود |
| Gool / WireGuard | جایگزین‌ها |
| Psiphon آلمان/آمریکا | آزمایشی؛ فقط انتخاب کشور خروجی اینجا ممکن است |

«فقط اینستاگرام» یعنی فقط اینستاگرام (و Instagram Lite) از VPN رد می‌شود و بقیه‌ی گوشی مستقیم می‌ماند.

## پنل مدیریت

- داخل برنامه روی عنوان «زهرا VPN» **۵ بار** بزنید. رمز پیش‌فرض `1234` است؛ همان‌جا عوضش کنید.
- فایل `servers.json` را روی GitHub (مثلاً `raw.githubusercontent.com/...`) ویرایش کنید، آدرسش را در پنل بدهید.
  همه‌ی گوشی‌ها لیست سرورها را از همان‌جا می‌گیرند. فقط پرچم‌های امنِ هسته پذیرفته می‌شود
  (`--upstream`, `--bind`, `--routes` و … رد می‌شوند).
- لاگ زنده‌ی هسته برای عیب‌یابی همان‌جاست.

## محدودیت‌ها (صادقانه)

- این کد **روی گوشی واقعی تست نشده** و اینجا کامپایل هم نشده. اگر Actions خطا داد، متن خطا را بفرستید تا درست شود.
- روی ایرانسل/رایتل چیزی را نمی‌شود قبلاً تضمین کرد؛ اپراتورها هر چند وقت یک‌بار روش‌ها را می‌بندند.
  برای همین چند روش هست. اگر هیچ‌کدام وصل نشد، لاگ را از پنل مدیریت کپی کنید.
- Aether سرور اختصاصی ندارد؛ تونل از شبکه‌ی Cloudflare WARP می‌گذرد، نه سرورهای آلمان/آمریکای خودتان.
  «انتخاب کشور» فقط با Psiphon ممکن است (آزمایشی: مسیر پوشه‌ی `pt/` در اندروید تست نشده).
  سرور اختصاصی یعنی VPS جدا و پروتکل دیگر؛ مثلاً Xray، که کار دیگری است.
- Aether مجوز AGPL-3.0 دارد: متن‌باز بماند و اعتبار هسته حفظ شود. نام برنامه را عوض کرده‌ام (مطابق سیاست علامت تجاری آن‌ها).
